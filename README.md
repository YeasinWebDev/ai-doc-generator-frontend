# DocGen AI — AI-Powered Documentation Generator

Connect your GitHub repositories and let AI create beautiful, comprehensive documentation automatically.

## ✨ Features

- **GitHub OAuth login** — one-click authentication with GitHub ("Continue with GitHub")
- **Repository browser** — search (debounced) and paginate through your GitHub repositories
- **AI documentation generation** — select a repository and generate documentation via the backend AI service
- **Document library** — browse all documents you've generated
- **Markdown viewer** — rendered with GFM support (tables, task lists, etc.) plus one-click copy to clipboard
- **Secure session handling** — cookie-based auth with automatic redirects for logged-in/logged-out states

## 🚀 Getting Started

### Prerequisites

- **Node.js** 20+ and npm
- Access to the running **DocGen AI backend** (see [Backend API](#backend-api) below)

### Installation

```bash
# Clone the repository
git clone https://github.com/YeasinWebDev/ai-doc-generator-frontend.git
cd ai-doc-generator-frontend

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. You'll be greeted by the login page — sign in with GitHub to reach the dashboard.

## 🔌 Backend API

This frontend is a client for the DocGen AI backend. All `/api/*` requests are transparently proxied to the backend service via [Next.js rewrites](https://nextjs.org/docs/app/api-reference/config/next-config-js/rewrites) in `next.config.ts`:

```ts
rewrites: async () => [
  {
    source: "/api/:path*",
    destination: "https://ai-doc-generator-chi.vercel.app/api/:path*",
  },
],
```

To point the app at a different backend (e.g. a local instance), update the `destination` URL in `next.config.ts`.

**Key endpoints used by the frontend:**

| Endpoint | Purpose |
| --- | --- |
| `GET /api/auth/me` | Check the current session / get the authenticated user |
| `GET /api/auth/github` | Start the GitHub OAuth flow |
| `POST /api/auth/logout` | End the session |
| `GET /api/documentation` | List the user's GitHub repositories (search + pagination) |
| `POST /api/documentation` | Generate documentation for a selected repository |
| `GET /api/documentation/user/documents` | List documents generated by the user |
| `GET /api/documentation/:id` | Fetch a single generated document |

> **Note:** `NEXT_PUBLIC_BACKEND_URL` may be set in `.env.local` for environment-specific configuration, but requests are currently routed through the rewrite proxy above.

## 🔄 How It Works

1. **Sign in** — the landing page redirects to GitHub OAuth via the backend; the session is stored in an HTTP-only cookie.
2. **Pick a repository** — from the dashboard, browse/search your GitHub repositories and select one.
3. **Generate** — the backend analyzes the repository and generates documentation with AI (OpenRouter-powered).
4. **View & copy** — open the generated document, rendered as rich Markdown, and copy it with one click.

## ☁️ Deployment

The easiest way to deploy is with the [Vercel Platform](https://vercel.com/new) — the same platform hosting the backend instance.

1. Push your changes to the repository.
2. Import the project into Vercel.
3. Deploy — the API rewrites in `next.config.ts` work out of the box on Vercel.

See the [Next.js deployment documentation](https://nextjs.org/docs/app/building-your-application/deploying) for more details.
